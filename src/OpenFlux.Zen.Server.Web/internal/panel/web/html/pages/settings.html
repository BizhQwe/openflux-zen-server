OpenFlux Zen Server

Веб-панель управления и служба сервера OpenFlux Zen Server (BizhQwe/openflux-zen-server). Отвечает за интерфейс управления, учётные записи администратора, фоновую службу системы и настройку туннелей.

Версия OpenFlux: 0.7.3
Версия веб-панели: 1.0.0
Доступная версия: 1.0.0
Дата релиза: —
Что нового в обновлении: Релиз на GitHub

Управление сетевым размещением

—

Настройте, откуда разрешён доступ к веб-панели сервера. Вы можете включить несколько вариантов одновременно.

Этот компьютер (Localhost)
Локальная сеть (LAN / Wi-Fi)
Отключено
Localtunnel (Интернет)
Отключено
Собственный домен / IP
Отключено

Пустое поле — частные подсети сетевых интерфейсов. Можно указать свои частные подсети через запятую. Публичный HTTP всегда закрыт.

Для внешнего доступа используйте HTTPS через домен. Полный URL укажите для уже настроенного reverse proxy.

В ссылке есть секретный путь для защиты от сканеров и ботов. После обновления прежняя ссылка перестанет работать.
