# OpenFlux Zen Server v1.1.0

Ядро обновлено с OpenFlux v0.7.3 до официального v0.13.0. Локальные патчи панели проверены до обновления и перенесены: IPC-статус клиента, счётчики IPv4-трафика, отдельные хранилища cookies, Telemost URL и Linux L3 guard.

- Добавлены Bitrix24, Mixed/Striped-группы, параметры каналов и сетей, исходящий SOCKS5-прокси для L4 и иконка Bitrix24.
- Ссылки для Cups.online и Avito необязательны: сервер может создавать комнаты автоматически. Ошибки создания комнат Avito теперь видны без включения debug.
- Формат ссылок сохранён совместимым с оригинальным OpenFlux v0.13.0. Обычный Multi учитывает настройку строгого согласования и сохраняет штатный classic fallback.
- Скрипты build и package-release по умолчанию собирают все семь платформ; добавлен package-release.ps1. Упаковка проверяет комплектность и SHA-256.

Проверены тесты и статический анализ, обмен 1 МиБ через Direct/SOCKS5 с чистым ядром v0.13.0, чтение ссылок восьми штатных типов и Multi оригинальным декодером. APK и графические клиентские приложения отдельно не запускались.

Известные ограничения:

- Mixed и Bitrix24 требуют ручной настройки совместимого клиента и исключаются из ссылок/QR. Остальные каналы Multi продолжают экспортироваться. Для Striped нужна поддержка на обеих сторонах.
- Avito может отвечать HTTP 403 при автоматическом создании комнат, даже когда сайт работает в браузере. Запрос ядра совпадает с апстримом; обход ограничений сервиса и изменение протокола транспорта не добавлялись.

Установщики: Windows amd64/arm64/386 и Linux amd64/arm64/386/armv7. Для каждого установщика опубликована SHA-256, общий список — SHA256SUMS.txt. Скрипты install.sh/install.ps1 доступны отдельными файлами релиза.
