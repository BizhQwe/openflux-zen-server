# OpenFlux Zen Server v1.1.1

Обновление OpenFlux Zen Server v1.1.1 включает автоматический выпуск TLS-сертификатов (HTTPS) в установщике и обновлённое ядро OpenFlux v0.13.0.

### Быстрая установка

**Linux:**
```bash
curl -sSL https://raw.githubusercontent.com/BizhQwe/openflux-zen-server/main/scripts/install.sh | sudo sh
```

**Windows (PowerShell от имени Администратора):**
```powershell
irm https://raw.githubusercontent.com/BizhQwe/openflux-zen-server/main/scripts/install.ps1 | iex
```

### Что нового:
- **Автоматический выпуск TLS/HTTPS в установщике**:
  - При выборе прямого подключения по домену установщик сам автоматически запрашивает и выпускает сертификат Let's Encrypt / ACME через HTTP-01 challenge (порт 80).
  - Сервер запускается сразу с HTTPS, и по завершении установки выводится готовая ссылка `https://...` — без необходимости ручной настройки.
  - Сохранена локальная HTTP-проверка (localhost), благодаря чему мониторинг службы и внутренние health-check работают стабильно в любых окружениях.
- **Обновление ядра OpenFlux до v0.13.0**:
  - Все локальные патчи проверены и перенесены: IPC-статус клиента, счётчики IPv4-трафика, раздельные хранилища cookies, Telemost URL и Linux L3 mark.
  - Поддержка новых транспортов и каналов: Bitrix24 (с единым стилем иконки), группы Striped/Mixed, автосоздание комнат Avito и Cups.online.
- **Автономность и надёжность**:
  - Единые самодостаточные бинарные установщики под 7 архитектур (Windows/Linux) с проверкой целостности SHA-256.
