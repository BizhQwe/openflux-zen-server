# OpenFlux Zen Server v1.1.2

Исправления безопасности панели и установки. Версия ядра OpenFlux остаётся 0.13.0.

Релиз пересобран 19 октября 2026: исправлено автовключение LAN при выборе домена; состав вложений сокращён до установщиков и контрольных сумм. Если уже установлена ранняя сборка 1.1.2, скачайте установщик заново и повторите установку с выбором домена. Автоматическая проверка обновлений не предлагает замену той же версии.

- Удалён показанный текст Mixed из формы туннеля, русских и английских переводов.
- Выдача сессий использует актуальные реквизиты. Смена пароля, имени или секретного пути атомарно завершает прежние сессии. Запрос настроек, начатый до изменения реквизитов, не может восстановить старые значения.
- Проверка Origin для изменяющих запросов учитывает схему, адрес и порт; запросы браузера с `Sec-Fetch-Site: cross-site` отклоняются. Существующий Bearer API сохранён.
- Linux/Windows bootstrap и автообновление проверяют SHA-256 установщика до запуска. Отсутствие или несовпадение суммы отменяет выполнение. SHA-256 защищает целостность загрузки; доверие к издателю и GitHub сохраняется.
- Обновление использует закрытый случайный каталог и исключительное создание файлов. Убраны предсказуемые временные имена и подстановка путей в shell/batch-код. На Windows останавливается только обновляемый процесс; Linux helper отделён от службы systemd.
- Выбранная версия загружается только из её тега, без подмены на `latest`. Загрузка ограничена HTTPS, размером и таймаутами.
- Минимальный Go обновлён до 1.26.9 с [исправлениями безопасности TLS/HTTP и других пакетов](https://go.dev/doc/devel/release#go1.26.9).
- Выбор прямого подключения по домену в установщике выключает дополнительный LAN-доступ, сохраняя публичный listener и существующие HTTPS-настройки. Сохранённый домен остаётся локальным значением по умолчанию при повторной установке.
- CLI показывает домен/Localtunnel перед дополнительными локальными адресами.
- В релизе только семь установщиков, индивидуальные SHA-256 и `SHA256SUMS.txt`. `install.sh`, `install.ps1` и их суммы не прикладываются; bootstrap остаются в исходниках для установки одной командой. CI загружает вложения по явному списку.

## Совместимость клиентов

Сохранены `openflux://v1/`, содержимое ссылок и QR, шифрование, KDF/context, wire v2, classic fallback и согласование Session. Изменения не требуют нового формата конфигураций OpenFlux Android/Desktop.

Поддерживаемые форматом v0.13.0 транспорты: Yandex, VYandex, Boards, Mail.ru, Cups.online, Avito, Direct, Telemost. Mixed и Bitrix24 по-прежнему не экспортируются в штатный QR; для них нужны возможности и настройка соответствующего клиента. Удаление подсказки не расширяет поддержку формата.

Статус сборок, повторной проверки совместимости и ограничения проверки безопасности: [валидация 1.1.2](https://github.com/BizhQwe/openflux-zen-server/blob/v1.1.2/docs/releases/v1.1.2-validation.md).
